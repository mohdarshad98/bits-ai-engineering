# BITS AI Engineering — Practical Projects

## About This Repository

This repository documents my practical learning journey in AI and Machine Learning Engineering alongside the BITS Pilani Digital AI Engineering & MLOps program.

The goal is to build a strong foundation in machine learning while progressively developing the skills needed to design, evaluate, validate, and engineer reliable AI/ML systems.

Rather than collecting notebooks, this repository focuses on meaningful experiments, documented decisions, and evidence of increasing technical depth.

## Engineering Approach

Projects emphasize sound data handling, meaningful baselines, justified modelling choices, rigorous evaluation, reproducibility, and progressively stronger engineering practices.

## Projects

### 1. [Credit Default Risk Prediction](./credit-default-risk-prediction/)

- **Problem:** Binary classification to predict credit card payment defaults using historical customer data from the UCI Machine Learning Repository.
- **Solution Implemented:** Established a rule-based baseline, then built a reproducible Logistic Regression pipeline with preprocessing and evaluated model performance through threshold comparison, false-negative analysis, and class weighting.
- **Key Learning:** Data exploration, target imbalance, categorical encoding, feature scaling, reproducible splitting, confusion-matrix analysis, and precision–recall trade-offs.
